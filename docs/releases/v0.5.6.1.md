# 🔧 Telegraphica v0.5.6.1 — Workshop And Download Micro-Patch

Telegraphica v0.5.6.1 is a focused micro-patch for the unified Intel `x86_64`
release supporting OS X 10.8 through macOS 10.13. It keeps the feature set and
verified call transport from v0.5.6 while improving downloads, media loading,
link previews and Workshop compatibility.

## Workshop

- Fixed updated Workshop plugins and games failing to open after installation.
- Kept strict package validation while accepting the verified installed bundle
  version when an older module binary reports stale internal metadata.
- Aligned bundled Workshop source versions with their signed package metadata.

## Downloads And Media

- Added document download progress directly to message cards.
- Made the download icon and the “Download” label start the same action.
- Added loading spinners for media that has not finished downloading yet.
- Added a completed-file state and a Dock notification for the Downloads folder.
- Added a setting to disable received link previews on slower Macs.
- Improved the quality and layout of received link-preview images.

## Compatibility

- Preserved one application bundle and one HFS+ installer for OS X 10.8 through
  macOS 10.13 on Intel Macs.
- Preserved the exact audio/video call transport validated for v0.5.6.
- Does not republish Workshop packages; the host-side compatibility fix works
  with the module updates already available from the Workshop catalog.

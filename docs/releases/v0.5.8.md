# Telegraphica v0.5.8 — Comments, reactions and smoother navigation

This update improves everyday reading and navigation in the unified Intel application for OS X 10.8 through macOS 10.13.

## Changes

- Channel comments open the linked discussion and retain the active thread during chat-list and history refreshes. Back restores the parent conversation and draft.
- Discussion history fallbacks support legacy and current TDLib schemas and validate the requested chat and thread. Forum refresh preserves the selected topic.
- Comment counters update for album members. Labels use correct Russian, Belarusian and English plural forms.
- Reactions have compact individual badges, readable whole-number counters, centred emoji and automatic wrapping. All ordinary reactions are displayed instead of limiting the list to three. Album updates preserve the other members' counts.
- Open conversations subscribe to channel and supergroup updates asynchronously. Stale navigation results are discarded.
- Thumbnail prefetch recovers after cache eviction and briefly backs off failed loads. Diagnostic redaction reuses compiled expressions. These reduce specific repeated work; no overall frame-rate improvement is claimed.
- Message time and delivery markers stay together. Media loading indicators follow active loads, and older-history loading requires the top rows to be visible.
- Text and composer buttons have consistent hover, pressed and disabled feedback.
- Focused helpers now own discussion navigation, thread metadata, reaction parsing and layout. Rebuilds preserve the verified call transport before cleaning old outputs.

The bundled TDLib runtimes and previously verified call transport are unchanged. Runtime capability limits remain described in [TDLib capabilities](https://github.com/MiChiRose/telegraphica/blob/main/docs/tdlib-capabilities.md).

## Verification

The automated suite passed on the native development host and Intel OS X 10.9.5 with Xcode 5.1.1/Python 2.7. The legacy build, isolated launch, binary compatibility audit and signature verification passed. Live checks covered session restoration, comment opening, refresh, return navigation and reactions; the user approved the development candidate.

OS X 10.8 and macOS 10.13 were not executed on physical systems in this iteration. Deployment, architecture and bundled fallback checks provide supporting compatibility evidence.

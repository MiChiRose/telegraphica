# 🧭 Telegraphica v0.5.3 ✦ Everyday Telegram Workflows

Telegraphica v0.5.3 expands the unified Intel `x86_64` client for OS X 10.8
through macOS 10.13 with the largest set of daily-use Telegram workflows added
since the public beta began. The same application bundle still serves the
complete supported OS range and selects legacy fallbacks at runtime.

## Chats, Contacts And Profile

- Added native Contacts and Calls navigation while keeping calls clearly marked
  as unavailable.
- Added contact search, direct chat opening, profile details, add/remove
  actions, invitations, and contact sharing.
- Added private-chat, group, channel, and secret-chat creation, invite-link
  joining, leaving, and archive management.
- Added chat information, participant lists, member roles, restrictions, bans,
  invite links, join requests, event log, and slow-mode controls where TDLib
  permits them.
- Added profile editing for name, surname, username, biography, and avatar.
- Added compact and expanded chat-list layouts, reliable one-click search
  navigation, unread-position restoration, mute indicators, and scrollable
  drawer folders.

## Messaging And Media

- Added bold, italic, underline, strikethrough, spoiler, and monospace
  formatting through Telegram message entities.
- Added silent, scheduled, and send-when-online messages plus link-preview
  controls.
- Added GIF animations, video notes, contacts, locations, live locations,
  venues, dice, regular polls, and quizzes.
- Added a shared Download Manager with filtering, pagination, progress,
  retry/cancel, Save As, Finder reveal, preview/playback, and cache deletion.
- Added viewport-based unread handling so a long unread conversation opens at
  the last read boundary instead of immediately marking the newest message as
  read.

## Folders, Notifications And Privacy

- Added chat-folder creation, editing, deletion, automatic inclusion/exclusion
  rules, explicit chats, and supported share-link management.
- Added synchronized per-chat mute, sound, and notification-preview settings.
- Added privacy-rule editing, blocked-user management, account inactivity TTL,
  per-chat/default auto-delete controls, active-session inspection, and remote
  session termination.

## Bots, Saved Messages And Workshop

- Added bot command panels, inline results, callback buttons, reply keyboards,
  and safely confirmed Login URLs.
- Added a focused Saved Messages organizer with topics, history, media
  thumbnails, tag display, and free-limit topic pinning.
- Added an optional Retro Console Workshop module for user-supplied compatible
  game files and emulator cores.
- Added a project policy and automated checks that prohibit Telegram commerce
  request types. Premium, Stars, payments, subscriptions, paid media, gifts,
  boosts, and other purchase flows remain outside Telegraphica.

## Location And Stability

- Added a Mavericks location picker with TDLib map thumbnails, MapKit
  current-location services and system pin rendering, map dragging, zoom, and
  map previews inside conversations.
- Removed text address search temporarily after reproducing a legacy async
  lifecycle crash.
- Closing, cancelling, or sending from the picker now invalidates pending map
  work, stops location tracking, and detaches callbacks before the window
  disappears.
- Fixed Keychain/bootstrap regressions, retained TDLib configuration across
  legacy rebuilds, and hardened legacy AppKit table-cell model retention.

## Known Limitations

- Voice, video, and group calling are not implemented in this release; the
  Calls destination remains a placeholder.
- Text address search is temporarily unavailable in the location picker. Use
  the map, pin, zoom controls, or **I'm here** on OS X 10.9 and newer.
- OS X 10.8 has no native MapKit framework, so the interactive location picker
  is unavailable there. The rest of the client continues to use the unified
  Mountain Lion-safe fallback lane.
- Premium-only Saved Messages tag editing/search and all paid Telegram
  operations are deliberately unavailable.

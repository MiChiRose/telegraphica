# 📹 Telegraphica v0.5.6 — Video Calls And QR Login

Telegraphica v0.5.6 is one unified Intel `x86_64` release for OS X 10.8 through
macOS 10.13. It adds experimental one-to-one Telegram video calls on OS X 10.9
and newer while preserving the Mountain Lion fallback in the same app bundle.

## Video Calls

- Added incoming and outgoing Telegram video calls with encrypted signaling,
  remote video, local camera preview, microphone, speaker and camera controls.
- Added automatic portrait and landscape presentation for remote video.
- Added dynamic connection-quality indicators and refined call status layout.
- Added an AVFoundation camera path and a Mavericks-safe monotonic clock for
  VP8 encoding, based on the transport build validated during legacy-Mac HITL.
- Audio-only calls remain available on OS X 10.9 and newer; OS X 10.8 shows a
  clear unsupported state without splitting the application or release.

## Login, Messages And Navigation

- Added Telegram QR-code login with clean cancellation back to the phone form.
- Added video-note recording with camera permission and a 60-second limit.
- Added received link-preview cards and richer link-preview sending controls.
- Improved chat search, Saved Messages lookup, navigation to search results,
  unread-message boundaries and date separators.
- Added contact birthday notices and unknown-sender safety warnings.

## Reactions, Forums And Polls

- Added a larger scrollable system-emoji reaction picker and reliable local
  reaction refresh after Telegram accepts a reaction.
- Improved reaction bubble sizing, animation and alignment.
- Added forum-topic tabs and topic create, rename, close, pin and delete flows.
- Extended poll and quiz management.
- Added server-backed chat-folder ordering.

## Compatibility And Reliability

- Pinned the exact HITL-approved video-call transport checksum so release
  packaging cannot silently substitute an older call binary.
- Fixed legacy QR authorization cancellation, contacts refresh after QR login,
  video-note preview compositing and several forum/search refresh loops.
- Preserved one HFS+ installer and one application bundle for OS X 10.8 through
  macOS 10.13 on Intel Macs.

# ✨ Telegraphica v0.5.9 — Compact chats, calmer notifications & better downloads

An everyday comfort update for older Macs: less empty space in conversations,
clearer file downloads and notifications that respect what you have actually read.

## 💬 A cleaner conversation

- Short, single-line text messages show the text, time and delivery marks on one
  line. Adding a reaction moves reactions and time into a shared lower footer.
- Reaction and timestamp layout stays inside the bubble during wrapping and animation.
- **Shift + Enter** inserts a new line; **Enter** sends the message.
- **Escape** closes the image viewer.
- The folder sidebar restores the profile avatar reliably after refreshes.
- Loading-spinner drawing and lifecycle fixes prevent visual leftovers and stop
  its timer when the window is hidden or minimized.

## 📥 Downloads you can follow

- Large-file downloads run asynchronously with progress, bounded retries and
  recovery from stalled transfers instead of a short synchronous timeout.
- A wider, collapsible side panel shows the filename, downloaded bytes and progress
  while you continue using chats. Closing it leaves the transfer running.
- **Pause / Resume** and **Cancel** are available alongside a redesigned download
  manager with readable action labels, clearer states and **Show in Finder**.
- Interrupted jobs use stable file identity when restored. Paused jobs stay paused,
  and a long completed-download history no longer discards unfinished transfers.

## 🔔 Notifications that keep their meaning

- Opening the app after a long break no longer replays a burst of old message alerts.
- Delivered notifications are removed after authoritative read updates, including
  reads synchronized from another Telegram client.
- A minimized window does not mark its selected conversation as read: new unread
  messages, the Dock count and Notification Center entries stay until they are read.
- Stale background callbacks cannot apply notification results to a replacement client.

## 🌿 Motion and economy mode

- Lightweight message and section transitions add motion to everyday navigation.
- Economy mode disables optional interface animations; hidden or inactive views
  stop unnecessary animation work.
- Theme-aware colors and spacing keep reactions and download controls readable.

## ✅ Verification and known test limits

The full automated suite passed on the development host and Intel OS X 10.9.5
with Xcode 5.1.1. Independent reviews covered asynchronous ownership, read receipts,
download restoration, keyboard behavior, layouts and legacy compatibility.
Live checks covered compact messages, reaction changes, text selection, image
Escape, navigation, notification persistence while minimized, foreground read
cleanup, download controls and a roughly 290 MB ZIP with all entries CRC-checked.

Physical execution on OS X 10.8 and macOS 10.13 was unavailable. The common
10.8 deployment target, architecture, binary dependencies and bundled fallback
checks provide supporting compatibility evidence. Paused-download restoration
after restart passed production-component tests; an uncached transfer across an
actual application restart was not separately observed. No measured CPU, heat or
frame-rate improvement is claimed.

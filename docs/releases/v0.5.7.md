# ✨ Telegraphica v0.5.7 — A More Capable Legacy Telegram

Telegraphica v0.5.7 is a substantial update to the unified Intel `x86_64`
application for OS X 10.8 through macOS 10.13. It expands free Telegram
functionality, improves media responsiveness and strengthens the internal TDLib
architecture without splitting the legacy release lane.

## Telegram And Account Features

- Completed the phone, code, email, QR and two-factor authorization state flow.
- Fixed QR-login and password-recovery button layout on legacy AppKit.
- Added capability-aware advanced chat folders: ordering, sharing, invite-link
  management, recommendations and server-reported limits.
- Added secret-chat creation, key visualization and destructive-action guards.
- Added server-backed reaction catalogs, reaction-user lists and safe custom
  emoji fallbacks for characters unavailable on an old system font.
- Preserved rich-text entities when receiving and sending formatted messages.

## Media, Downloads And Storage

- Moved message thumbnails, sticker thumbnails, inline GIFs and animated-image
  decoding away from AppKit layout paths to bounded background work.
- Added independent audio/video playback speeds and optional sequential audio
  playback.
- Restored interrupted download queues and separated auto-download policy for
  photos, videos, documents and voice messages.
- Added media-type and current-chat filters to storage cleanup while preserving
  cloud content and explicit Downloads copies.

## Accessibility And Reliability

- Added a legacy-safe accessibility foundation with VoiceOver descriptions for
  chat and message content.
- Split account, search, file and storage TDLib operations into focused
  components with cancellable request lifetimes.
- Added runtime TDLib capability reporting and provenance/ABI validation for
  both bundled TDLib lanes.
- Fixed stale storage-window callbacks and restored the current-user avatar in
  the drawer and profile.

## Compatibility And Validation

- Keeps one application bundle and one HFS+ installer for OS X 10.8 through
  macOS 10.13 on Intel Macs.
- Preserves the exact call transport already shipped and HITL-validated in
  v0.5.6 and v0.5.6.1; its manifest now matches the released binary checksum.
- Automated compatibility, policy, localization, security and component probes
  pass for the release source.
- The unified candidate was built and launched on OS X 10.9.5 with the existing
  Telegram session preserved. OS X 10.8 remains covered by the shared 10.8
  deployment target and Mountain Lion TDLib fallback; no separate build exists.

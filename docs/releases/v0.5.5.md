# 📞 Telegraphica v0.5.5 — Audio Calls

Telegraphica v0.5.5 continues the unified Intel `x86_64` release for OS X 10.8
through macOS 10.13 and introduces Telegram-compatible one-to-one audio calls
on OS X 10.9 and newer.

## Audio Calls

- Added outgoing and incoming Telegram audio calls with call history, contact
  selection, ringing, answer, hang-up, microphone mute and per-call speaker
  mute controls.
- Added modern call-protocol negotiation, encrypted signaling, Telegram
  reflector routing and WebRTC audio processing with echo cancellation.
- Call history shows direction and duration and supports deleting individual
  entries from its context menu.
- The New Call field starts empty and keeps the Call button disabled until the
  user explicitly selects a contact.
- OS X 10.8 keeps the same application bundle but shows a clear unavailable
  state for calls; chats and the rest of Telegraphica continue to work.

## Privacy And Media

- Added clear application-level microphone and location permissions with
  matching controls in Privacy and Storage.
- Improved voice-message playback layout and media-window sizing.
- Refined location selection and cancellation behavior on supported systems.

## Reliability

- Fixed call setup with current iPhone, Android and desktop Telegram clients.
- Added WebRTC echo cancellation and stable CoreAudio capture/playback.
- Pinned the HITL-approved audio-call transport so routine UI or packaging
  builds cannot silently replace it with an older cached binary.

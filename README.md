# Telegraphica

**Telegram for the Intel Macs that still have plenty of life left in them.**

Telegraphica is an independent, unofficial Telegram client for
**OS X 10.8 Mountain Lion through macOS 10.13 High Sierra** on Intel Macs.
It offers everyday messaging, folders and forum topics, photos and voice
messages, downloads, and a choice of Classic or Aqua appearance.
Telegraphica is not affiliated with Telegram.

Open the DMG and drag **Telegraphica** into **Applications**. If macOS blocks
first launch, Control-click the application and choose **Open**.

When updating, quit Telegraphica before replacing it. Keep your existing
settings and application data. Save important unsent text before restarting:
draft restoration remains a known issue in 0.6.2.

## Make it your own

To enable Aqua, open **Settings → Appearance → Interface → Aqua** and confirm
the restart. In Russian: **Настройки → Оформление → Интерфейс → Aqua**.

In Aqua, colors and materials are under **Settings → General → Aqua appearance**.
Chat backgrounds are under **Settings → Chats → Change background…**.
Classic remains available in the same interface selector.

While running, Telegraphica checks for updates once an hour. An available
update adds an indicator in Settings; it is not installed automatically.
You can also choose **Settings → Check for updates**.
